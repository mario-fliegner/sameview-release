Google Play Data Safety
========================

Last updated
2026-10

==================================================
APP OVERVIEW
==================================================

In normal use, SameView works locally and offline on the user's device.

The app:
- does not require a user account
- has no backend or cloud synchronization
- contains no analytics SDKs
- contains no advertising SDKs
- contains no crash reporting SDKs
- stores user data locally on the user's device
- declares the INTERNET permission solely for the optional DeinWackelbild order

The only case in which the app itself transmits user data off the device is the
optional DeinWackelbild order, and only after the user explicitly starts it
(see OPTIONAL DEINWACKELBILD ORDER).

==================================================
DEFINITION USED IN THIS DOCUMENT
==================================================

This document follows the Google Play Data safety definitions:

- "Collect" means transmitting data from the app off a user's device.
- User data that is only processed locally on the user's device and not sent
  off device does not need to be disclosed.

Earlier revisions of this document (2026-07) listed on-device data as
"Collected: Yes". That did not match the Google definition and did not match
the v1.0 submission record (05_Releases/2026-07-24_PlayStoreSubmission.docx:
no data types selected). On-device data is now listed separately below.

==================================================
DATA COLLECTION
==================================================

Photos
- Purpose: App functionality (optional DeinWackelbild print order). No other
  purpose applies.
- Collected: Yes
- Shared: No (see DATA SHARING)
- Required: No (optional feature, starts only after an explicit user action)
- Processed ephemerally: No. DeinWackelbild stores the images for up to
  24 hours (handoff not completed) or 30 days (completed order); they are not
  held only in memory (see OPTIONAL DEINWACKELBILD ORDER / Retention).
- Notes: Two prepared JPEG copies (reference + capture) are transmitted to
  DeinWackelbild when the user explicitly starts the order. The stored
  originals are not transmitted.

Other transmitted values (not a Data safety data type)
- Partner identifier (body field "partner" and partner key header): a constant
  of the app, not user data.
- Idempotency key: a random UUID per handoff attempt; not persisted, not a
  device or user identifier.
- Format, orientation, direction: product configuration values.
- Locale: the request field exists but is not sent (never set by the app).
- IP address: inherent to any network request. Google asks for IP addresses to
  be disclosed based on actual use (for example to determine location). It is
  not used that way (see Retention / use below), so it is not declared.

==================================================
DATA SHARING
==================================================

SameView does not transmit user data to developer servers.

User data only leaves the device when the user explicitly initiates one of:
- an export or the Android Share Sheet
- the optional DeinWackelbild order

Photos - Shared: No

Basis: Google Play guidance does not require a transfer to a third party to be
disclosed as "sharing" when it is "based on a specific user-initiated action,
where the user reasonably expects the data to be shared". The DeinWackelbild
transfer starts only after an explicit user action, and immediately before the
transfer the app discloses that the two images go to DeinWackelbild.de and that
ordering is completed there.

This document does not rely on the "service provider" exception.

Commission (decided 2026-10-07): SameView receives a 10% commission on orders
attributable to this handoff. The user-initiated-action exception is not
conditioned on the absence of a commercial relationship. The commission is paid
for attributable orders, not for data, and DeinWackelbild has confirmed that
image contents are not used for advertising, publication or profiling. The
commission therefore does not change "Shared: No".

Onward processing by DeinWackelbild (decided 2026-10-07): only the transfer from
the app to DeinWackelbild is assessed for SameView. DeinWackelbild's hosting
provider and Ecwid (which receives no image files) do not change SameView's
classification.

==================================================
DATA SECURITY
==================================================

- Normal use causes no network traffic
- The only network transmission by the app is the optional DeinWackelbild order
- That transmission uses HTTPS only:
  - the API base URL is fixed to https://deinwackelbild.de/wp-json/dwb/v1
  - the server-returned upload URL and checkout URL are rejected unless HTTPS
  - HTTP and HTTPS redirects are disabled in the HTTP client
  - targetSdk 36 with no network security config: cleartext traffic is
    blocked by the platform
- No automatic upload and no background upload
- In normal use, user data remains on the device
- User sessions are excluded from Android Auto Backup and device transfer
- No automatic cloud synchronization

==================================================
OPTIONAL DEINWACKELBILD ORDER
==================================================

What it is
- A separate optional feature to order a physical lenticular print (Wackelbild).
- Nothing is transferred through normal use of SameView.

When data is transferred
- Only after an explicit user action.
- Immediately before the transfer, the app discloses that the two images go to
  DeinWackelbild.de and that ordering is completed there.
- No automatic upload, no background upload.

What is transferred
- Exactly two prepared JPEGs: reference + capture.
- They are derived/prepared copies, not the stored originals.
- They contain no EXIF/GPS metadata.
- If the date option is enabled, the date text is rendered into the image pixels.
- Technical handoff values, including a partner identifier, format, orientation
  and direction.
- No SameView session ID and no external reference is sent.
- No analytics, telemetry or tracking data.

How
- HTTPS.
- The checkout/configurator then opens externally in a Chrome Custom Tab /
  browser. Data the user enters there is entered on the DeinWackelbild website,
  not in SameView.

Recipient / operator / seller
- O.Schulze / M.Monka GbR (DeinWackelbild), Wolfener Str. 32-34, 12681 Berlin, Germany
- The physical print order is completed with DeinWackelbild under its own terms
  and is separate from the SameView purchase on Google Play.
- SameView receives a 10% commission on orders attributable to this handoff.

Retention / use (confirmed in writing by DeinWackelbild, 2026-10; also stated in
https://deinwackelbild.de/datenschutz/)
- Handoff not completed: valid for 24 hours; the temporary files are then
  deleted automatically.
- Completed order: image, preview and production files are stored for 30 days
  from order confirmation, then automatically deleted from the active
  production system; existing production access is revoked.
- Legally required order, invoice and accounting data are stored separately
  according to the applicable retention periods.
- Image files may temporarily remain in technical backups until overwritten
  through the regular backup rotation. Backups are used exclusively for
  recovery. The rotation period is not known; accepted as a documented residual
  uncertainty (no further inquiry planned).
- Use: exclusively to create the preview, produce the ordered Wackelbild,
  process the order and handle directly related questions or complaints. Not
  used for advertising, publication, profiling or training AI models.
- In the normal SameView flow, image files are not transmitted to OpenAI,
  analytics or advertising services.
- DeinWackelbild's hosting provider processes the files as part of
  website/server operation.
- Ecwid receives the necessary product, partner and order information plus a
  protected production-access URL; the image files are not uploaded to Ecwid.
- SameView does not receive the transferred images back.

The public SameView privacy policy (section 7) states only the 24-hour and
30-day retention, a short backup note and a link to DeinWackelbild's privacy
policy. The further details above are kept here as internal documentation.

Never record the partner identifier value in this repository.

GOOGLE PLAY DECLARATION SUMMARY
==================================================

Does the app collect or share any of the required user data types
- Yes

Collected
- Photos (optional, purpose: App functionality, not processed ephemerally)

Shared
- None (user-initiated transfer; see DATA SHARING)

Not declared (processed on device only)
- Photos (stored originals)
- Videos
- Location
- User-generated content
- Files and documents (manual backup export)

Encryption in transit
- Yes (HTTPS)

Data deletion
- Answer: Yes (users can request that their data is deleted).
- Basis: Google allows this answer if collected data is automatically deleted
  within 90 days of collection. DeinWackelbild deletes the transferred images
  automatically after 24 hours (handoff not completed) or 30 days (completed
  order).
- Separately stored legally required order/accounting data: retention for legal
  compliance is permitted by Google; these records do not contain the images.
- Technical backups: images may remain until overwritten by the regular
  rotation, used exclusively for recovery. Considered acceptable as retention
  for a legitimate reason; rotation period unknown (accepted residual
  uncertainty).
- On the device: users delete individual sessions inside the app; uninstalling
  the app removes all private app data.
- SameView holds no server-side copy of the transferred images.
- No account exists, so no account deletion URL applies.

External checkout (decided 2026-10-07)
- Data the user enters in the DeinWackelbild checkout (Chrome Custom Tab) is not
  declared. Google's rule covers webviews whose code/behavior the app controls;
  a Custom Tab is the user's browser, and SameView does not control its content.
